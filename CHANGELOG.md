# Glide Shell — что нового

Новое — сверху. English: see [README.md](README.md); история ведётся по-русски.

- **v1.5** — автоматизация: правила «когда → если → сделать» во вкладке настроек «Автоматизация»
  (`Automation.qml` — движок, `AutomationView.qml` — конструктор). 16 событий (приложения, время, телефон, питание,
  заряд, блокировка, запись/демонстрация, VPN, запуск), условия по времени суток и питанию, 12 действий с паузами
  между ними, кнопка «выполнить сейчас», журнал срабатываний, пауза при зацикливании. IPC `panel automation`.
- **v1.4** — приватность. «Настройки» → «Уведомления» → «Приватность»: что показывать в уведомлениях (всё / без
  текста / только приложение — в острове, панели и подсказке колокольчика; картинка уведомления — только при «всё»);
  на записи и демонстрации экрана уведомления сами сжимаются до «Новое уведомление · приложение» (`Notifs.privacy`).
  Окна выбранных приложений niri закрашивает на записи, демонстрации и скриншотах: `glide-niri.py privacy` пишет
  правила `block-out-from "screen-capture"` в `glide-privacy.kdl` (проверка `niri validate`, при ошибке — откат); их
  заголовки в баре, списке окон и меню дока на это время заменяются именем приложения (`Niri.titleFor`).
  «Не беспокоить» при демонстрации теперь срабатывает и на свою запись (wf-recorder). Запись экрана: выбор монитора,
  когда их несколько (`Prefs.recOutput`; по умолчанию — тот, где фокус).
- **v1.3** — цвет острова и сообщения между плагинами. Остров показывает все цвета сразу: камера (зелёный),
  микрофон (янтарный), а теперь и демонстрация или запись экрана (красный); если их несколько — неподвижный
  градиент заливки и обводки (`IslandTint.qml`). Плагины красят остров через `api.island.tint(цвет)` с новым
  разрешением `island` (не больше трёх цветов, после камеры, микрофона и экрана). Обмен с другими плагинами
  (`api.send` / `onMessage`) — теперь по разрешению `messages`; части одного плагина (раздел, служба, значок в баре)
  пишут друг другу без него — раньше такие сообщения терялись. Плагинам старого формата, одобренным целиком, `messages`
  выдано один раз при обновлении. Исправлена подсказка бара: когда капсула сдвигалась, контур уезжал, а текст
  оставался, и край обрезался — теперь капля едет вместе с капсулой. В документации — раздел «Производительность».
- **v1.2** — подсказка у значка плагина в баре: свойство `tip` (строка или `{title, rows, hint}`) показывается при
  наведении в той же капле, что у встроенных значков, обновляется на лету. `api` у раздела, элемента бара и службы
  плагина передаётся начальным свойством — есть уже в `Component.onCompleted` (раньше приходил чуть позже, и служба,
  вызвавшая `api.setTimeout` при создании, падала с «Cannot call method of undefined»). Примеры «Вода» и «Проверка
  API» — с подсказками.
- **v1.1** — закрыта дыра: сторонний плагин с `"api": 1` (или без поля) молча получал все разрешения — любой мог
  обойти согласие одной строкой. Теперь он просит всё и не получает ничего, пока человек не разрешит (по одному или
  «Разрешить всё…» — паролем, с предупреждением); до этого его команды и daemon не работают. Установленное до 1.1
  (сторонние плагины и свои виджеты API 1) одобрено один раз при обновлении (`Permissions.migrateLegacy`).
- **v1.0** — API плагинов версии 2 и разрешения, которые меняет только человек. Плагин с `"api": 2` перечисляет в
  `permissions`, что ему нужно (`exec`, `network`, `clipboard`, `notifications`, `windows`, `phone`, `system`), и
  получает это, только если разрешишь ты: «Настройки» → «Плагины» → «Разрешения» под плагином. Плагин может лишь
  попросить (`api.permissions.request`) — откроется вопрос; выдать — паролем от входа (PAM, при защите плагинов),
  забрать — сразу. Отказ запоминается, просить — не чаще раза за сеанс. Разрешения — в
  `~/.config/glide-shell/permissions.json` (`Permissions.qml`); правку файла в обход настроек оболочка отменяет и
  предупреждает. Без `exec` у плагина API 2 не запускаются `daemon` и команды кнопок. Код в обход `api`
  (`Quickshell.Io`, `Process`, `XMLHttpRequest`…) помечается под плагином. Плагины API 1 работают как раньше и
  получают всё — лишнее можно забрать. Новое в API для всех: `api.http`, `api.files` (своя папка в
  ~/.local/share/glide-shell/plugin-data), `api.setTimeout`/`setInterval`/`clearTimer`, `api.send` + `onMessage`
  (сообщения между плагинами), `api.tr`/`lang`, `api.log`/`warn`, `api.storage.keys`/`clear`, `api.openSettings`,
  `api.shellApi`, `api.dir`. D-Bus: `GetApiVersion`, `ListPlugins`, `OpenSettings`; команды `glide-shell plugins`,
  `settings`, `api`. docs/API и README — с оглавлением (`tools/docs-toc.py`, проверяется тестом) и ссылками
  «↑ к оглавлению»; разделы 3а «Новое в версии 2», 3б «Разрешения», 12 «Переход с версии 1 на 2».
  Заготовка `glide-plugin.py new` и пример «Вода» — на API 2. Тест контракта — версии 1 и 2.
  Проверка на взлом закрыла дыры: права решаются по реестру объектов api (`Permissions.register` — его заполняет
  код оболочки), а не по `api.owner`/`api.manifest`, которые плагин мог перезаписать и назваться встроенным или чужим
  плагином; хранилище, файлы, настройки, активности и сообщения — тоже от настоящего id; `api.shell` (доступ ко всей
  оболочке мимо разрешений) убран — внутри `Core`; служба плагина API 2 получала урезанный манифест и все права —
  теперь полный. Аудит ловит `import qs`-обходы (`Permissions`, `Core`, `Prefs.set`, свой `ApiScope`, `data:`).
  Пример `examples/plugins/apitest` — проверяет каждую функцию API: выключаешь разрешение — его строки становятся ✗.
- **v0.98** — исправлено: уведомления не закрывались крестиком в панели (ни карточка, ни группа). Карточки получают
  от Repeater копии записей, а удаление искало запись по ссылке на объект — копия не находилась, и уведомление
  оставалось (через IPC работало: там удаляются настоящие записи). Теперь `Notifs` ищет записи по `key`. Ещё: крестик
  есть и у свёрнутой стопки (закрывает её целиком); закрытое уведомление час не возвращается, если приложение
  присылает его заново (KDE Connect, пока уведомление висит на телефоне).
- **v0.97** — исправлено: уведомления не закрывались крестиком. Крестик стопки удалял первое уведомление, список
  перестраивался посреди цикла, и остальные падали с ошибкой («Cannot read property 'ns' of undefined»); крестик
  свёрнутой стопки убирал только верхнее, а на его место вставало следующее. Теперь `Notifs.removeMany` убирает разом,
  крестик свёрнутой стопки закрывает её целиком, в раскрытой — по одному.
- **v0.96** — безопасность плагинов: на экране блокировки «Войти без сторонних плагинов» — после правильного пароля
  выключаются все плагины из ~/.config (встроенные остаются; тестовая блокировка без пароля так не умеет); включать и
  выключать плагины в настройках — по паролю (PAM, как у замка; защиту можно снять тоже по паролю, плагин сам — нет).
  `api.exec` — под `setpriv --pdeathsig` (не остаётся сиротой при падении оболочки); повреждённое хранилище плагина
  сохраняется как `.broken`. docs/API: точный справочник (типы, что возвращает, обновляется ли само, ошибки),
  раздел 10 «Безопасность, данные и совместимость» (песочницы нет, как выключить сломанный плагин, что при ошибках,
  где данные, правила версий), раздел 11 «Рецепты».
- **v0.95** — `api.exec(argv, {stdin, timeout, env}, (code, out, err) => …)`: запуск с результатом, тайм-аутом
  (60 с) и отменой (`job.cancel()`). Поле `api` в plugin.json проверяется: нет — версия 1, новее или не число —
  плагин не грузится, причина видна в «Плагинах». Тест «контракт API v1» (`tests/test_api_contract.py`, в install.sh):
  все обещанные поля api, токены Theme, методы и сигналы D-Bus и поля plugin.json — на месте и описаны в обоих
  справочниках; убрать что-то незаметно больше нельзя.
- **v0.94** — фоновая работа плагинов: поле `"service": "Service.qml"` — QML без интерфейса живёт с оболочкой (таймеры,
  активности), не перезапускается при открытии панели. docs/API, раздел 4а: где и сколько живут раздел, элемент бара,
  служба и daemon; имена свойств, которые заняты (`left`, `top`, `data`… — «Cannot override FINAL property»); Qt 6.8+.
  IPC `panel activityAct ID click|action|close`. Проверено вторым плагином другого ИИ («Фокус-таймер»).
- **v0.93** — правки плагина (раздел и элемент бара) подхватываются при следующем открытии панели: `qp-discover` отдаёт
  время изменения файлов, к адресу QML добавляется `?v=` (раньше элемент бара брался из кэша до перезапуска).
  Значок виджета — символом или кодом, как у плагинов. docs/API: все поля plugin.json прямо в справочнике
  (`wide`, `handoff`, `output`, `confirm`, `close`, `contextActions`…), пример `api.activity` с `onAction`/`onClick`.
- **v0.92** — API по отзыву стороннего разработчика (плагин «Вода», написанный другим ИИ только по документации,
  заработал с первого раза): `api.date` и `api.today` (обновляются на каждой минуте и после сна — смена дня без

- **v0.91** — значки и прогресс программ в доке по стандарту Unity LauncherEntry (`LauncherEntries.qml`, слушает
  `dbus-monitor`): число непрочитанных — красным кружком, загрузка — полоской под значком, «срочно» — красной точкой;
